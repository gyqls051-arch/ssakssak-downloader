## 감사에서 나온 제약 (설계할 때 반드시 반영)

**플레이어**
- 액센트가 런타임 CSS 변수 `--accent-rgb`(공백 구분 RGB)라서 새 색도 `R G B` 삼원색으로 써야 `bg-accent/20` 알파가 산다
- `useAccentColor.ts`의 `ACCENT_PRESETS[0]`도 같이 바꿔야 기본값이 바뀐다 (localStorage `offcut.player.accent` 저장값은 기존 사용자에 남음)
- 파형 색이 ffmpeg에 `'255,107,53'` 문자열로 전달됨(`electron/ipc.js`) — 같이 갱신
- `electron/windows.js`의 `backgroundColor '#0a0a0a'`를 Tailwind `bg.base`와 같이 안 바꾸면 첫 페인트 때 색이 번쩍인다
- 시크 썸네일 오버레이는 data URL 인라인 HTML이라 토큰을 손으로 복제해야 함
- `offcut.player.*` localStorage 키, `window.offcut` 브리지, `offcut-cap://` 프로토콜은 **이름 바꾸면 사용자 데이터 날아감** — 건드리지 말 것
- 프로덕션 CSP에 네트워크 폰트 불가 → Pretendard는 번들해야 함(용량 고려)

**한글뷰어**
- CSP상 웹폰트 CDN 불가, 배너 원격 이미지도 차단 → 폰트·이미지는 로컬 번들 + 라이선스 고지 필요
- 문서 페이지는 **항상 흰 종이**여야 함. 크림색 배경을 쓰면 스테이지와 종이가 뭉개지므로 대비 확보 필요
- `src/main/index.ts`의 `backgroundColor '#1e1f22'`를 `--bg`와 같이 갱신
- 접근성 유지: `:focus-visible` 3px 앰버 아웃라인, 강제 색 대비 모드, reduced-motion
- **E2E가 클래스명·창 제목에 의존** (`.empty`, `.dropzone__card`, `#open-document-button`, 제목에 '싹싹김치' 포함) — 바꾸면 테스트 깨짐
- 검증: `npm run typecheck`, `npm run lint` 맥에서 통과 확인됨. `npm run test:e2e`도 맥에서 돎

**문서뷰어(mac Tauri)**
- 한글뷰어와 기능이 겹친다(HWP/PDF). **같은 "문서 뷰어" 제품의 mac 에디션으로 볼지, 하나를 접을지 브랜드 아키텍처에서 결정해야 함**
- 저장소가 OFFCUT 계정(`rlagyqls051-create/ssakssak-viewer`)에 있음 — 싹싹김치 계정으로 옮길지 결정 필요
- `TRADEMARK.md`와 `brand/README.md`가 이 프로젝트 마크로 '오프컷'을 같이 적어놔서 문구 수정 필요
- 종이는 어떤 테마에서도 `#ffffff`. 검색 하이라이트가 `mix-blend-mode: multiply`라 라이트 종이 전제
- mac 타이틀바 오버레이: 툴바 좌측 84px는 신호등 버튼 자리
- `tauri.conf.json`의 `productName`은 ASCII 유지 (설치 경로가 됨), identifier·ProgId 바꾸면 업그레이드·파일연결 깨짐

**블랙홀**
- CEF 99(크롬 99) 런타임 → `color-mix()`, `oklch()`, `:has()`, CSS 중첩, `@container` **못 씀**. 토큰은 평범한 hex/rgba로
- 프리미어 다크 UI 안에 들어가므로 크림 배경은 부적합 → **다크 변형 필요**
- 대비 계산됨: 진녹색 `#2F6B4F`를 `#232323` 위 텍스트로 쓰면 2.50:1 (기준 미달) → 텍스트·포커스용 밝은 틴트가 따로 있어야 함. 흰 글자 on `#2F6B4F`는 6.29:1로 양호
- 패널 최소 260x280에서도 레이아웃이 살아야 함
- `js/CSInterface.js`는 어도비 원본이라 수정 금지, `jsx/host.jsx`는 ES3 유지
- 이 저장소는 별도 구현 계획 진행 중 (8개 작업 중 2개 완료, **작업 3부터 재개**) — 디자인 작업이 그 계획의 작업 7(패널 UI)과 겹치므로 순서 조율 필요
