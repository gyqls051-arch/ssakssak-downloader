### 작업 A: 새 버전 알림이 사용자에게 안 뜨는 버그 🔴 최우선

**문제**: `UpdateChecker._interpret`(main.py ~L815)가 `kind="new_version"` 판정(release_notes, download_url 포함)을 만들어 주지만, 소비자인 `Api._kill_and_update`(main.py ~L1386)가 `killswitch`/`force_update`만 처리하고 `new_version`은 무시한다. → 일반 업데이트 알림이 사용자에게 절대 표시되지 않음. v1.7 배포 후 v1.6 사용자가 알림을 못 받는다.

**수정 1 — main.py `Api._kill_and_update` 재구성**:

```python
def _kill_and_update(self) -> None:
    decision = self._updater.fetch_decision()
    if decision is None:
        # 오프라인: 이전에 받은 정지가 있으면 유지
        if self._cfg.get("killed"):
            self._kill(self._cfg.get("killed_message") or "현재 사용이 중단되었습니다.")
        return
    if decision.kind == "killswitch":
        self._cfg["killed"] = True
        self._cfg["killed_message"] = decision.message
        self._settings.save(self._cfg)
        self._kill(decision.message)
        return
    # 킬스위치 아님 → 이전 정지 상태가 남아 있으면 해제
    if self._cfg.get("killed"):
        self._cfg["killed"] = False
        self._cfg["killed_message"] = ""
        self._settings.save(self._cfg)
    if decision.kind == "force_update":
        self._js(f"alert({json.dumps(decision.message + ' 업데이트가 필요합니다.')})")
        safe_open_url(decision.download_url)
    elif decision.kind == "new_version":
        # 새 버전 알림 배너 (강제 아님 — 사용자가 닫을 수 있음)
        self._js(
            f"updateAvailable({json.dumps(decision.latest_version)},"
            f"{json.dumps(decision.download_url or '')},"
            f"{json.dumps(decision.release_notes)})"
        )
```

주의: 기존 코드는 `else:` 분기에서 killed 해제를 했는데, 재구성 후에는 **killswitch 가 아닌 모든 경로에서 해제**되도록 위처럼 앞으로 뺀다 (force_update/new_version 때도 해제돼야 함 — 기존 동작보다 개선).

### 작업 C: addJob 레이스 — 초기 이벤트 유실 🟡

**문제**: `smartDownload`/`confirmDownload`(web_ui/index.html)가 `await api().start_download(...)` **후에** `addJob()` 을 호출한다. 파이썬 다운로드 스레드가 그 사이에 쏜 `dlProgress`/`dlError` 는 `if(!j) return` 으로 버려진다. 극단적으론 항목이 '대기 중' 상태로 영원히 남는다.

**수정**: 두 함수 모두 **addJob 을 먼저**, 실패 시 `removeJob(id)` 롤백. (`removeJob` → `api().forget_item()` 은 미등록 job_id 에도 안전함 — `_active.get`/`pop(..., None)` 사용 확인됨.)

`smartDownload`:

```js
async function smartDownload(url){
  setPasteLoading(true);
  let r;
  try { r = await api().analyze(url); } finally { setPasteLoading(false); }
  if(!r || !r.ok){ toast('분석 실패: ' + ((r && r.error) || '')); return; }
  const q = smartQuality(r), f = S.init.format || (S.init.formats && S.init.formats[0]);
  const id = 'd' + Date.now();
  addJob(id, r.title, r.thumbnail, subBadge(q, f));   // 먼저 등록 → 초기 이벤트 유실 방지
  const res = await api().start_download(id, r.url, q, f);
  if(!res.ok){ removeJob(id); toast(res.error || '시작 실패'); return; }
  toast('다운로드 시작 · ' + r.title);
}
```

`confirmDownload`:

```js
async function confirmDownload(){
  const r = S.analyze; if(!r) return;
  const isAudio = S.modalTab === 'audio';
  const quality = isAudio ? '음성만 (MP3)' : (S.modalQuality || r.quality);
  const fmt = S.modalFormat || (S.init.formats && S.init.formats[0]);
  const id = 'd' + Date.now();
  addJob(id, r.title, r.thumbnail, subBadge(quality, fmt));   // 먼저 등록
  const res = await api().start_download(id, r.url, quality, fmt);
  if(!res.ok){ removeJob(id); showModalError(res.error || '시작 실패'); return; }
  closePaste();
}
```

### 작업 D: '오늘 그만 보기'가 UTC 날짜 기준 🟡

**문제**: `maybeShowStart`/`closeStart` 가 `new Date().toISOString().slice(0,10)` 사용 → UTC라서 한국 시간 **오전 9시**에 "오늘"이 바뀐다 (새벽에 숨긴 팝업이 9시에 또 뜸).

**수정**: 로컬 날짜 헬퍼로 교체 (두 곳 모두):

```js
function todayLocal(){
  const d = new Date();
  return `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}`;
}
```

`maybeShowStart` 와 `closeStart` 의 `new Date().toISOString().slice(0,10)` → `todayLocal()`.

```js
/* ── 전역 붙여넣기: 창 어디서든 Ctrl+V 로 바로 분석 ── */
document.addEventListener('paste', e => {
  if(document.querySelector('.overlay.on')) return;             // 모달(약관 포함) 열림 → 무시
  if(e.target && e.target.tagName === 'INPUT') return;          // 입력칸은 기본 동작 유지
  const t = ((e.clipboardData && e.clipboardData.getData('text')) || '').trim();
  if(!/^https?:\/\//i.test(t)) return;
  if(S.smart) smartDownload(t);
  else { openPaste(); analyzeInModal(t); }
});
```
