# 개인정보 처리방침(배포 전 초안)

> **릴리스 차단:** 운영자 `RELEASE_BLOCKER_LEGAL_NAME`, 개인정보 문의처 `RELEASE_BLOCKER_PRIVACY_CONTACT`, 시행일 `RELEASE_BLOCKER_EFFECTIVE_DATE`를 확정하고 실제 동작과 법률 검토를 완료하기 전에는 배포할 수 없습니다.

## 1. 적용 범위

이 문서는 싹싹김치 비디오 다운로더 Windows 애플리케이션의 로컬 데이터 처리와 외부 네트워크 연결을 설명합니다. 운영 웹사이트 또는 GitHub가 자체적으로 처리하는 접속 기록에는 각 서비스의 정책이 적용될 수 있습니다.

## 2. 운영자가 수집하는 정보

현재 애플리케이션에는 운영자 자체 계정, 광고 추적 SDK, 원격 분석(telemetry), 사용자 파일 업로드 기능이 없습니다. 입력한 영상 URL, 내려받은 미디어, 브라우저 쿠키 내용 및 앱 로그를 운영자 소유 서버로 전송하지 않습니다.

## 3. 기기에서 처리·저장되는 정보

- 설정: 저장 폴더, 스마트 다운로드 여부, 브라우저 쿠키 사용 동의 여부, 약관 동의 버전
- 로그: 오류 및 상태 정보. URL의 사용자정보·경로·query·fragment는 기록 전에 제거
- 캐시: 검증된 ffmpeg, 다운로드 중간 파일, 업데이트 설치 파일
- 다운로드 결과: 사용자가 지정한 폴더의 미디어 파일

기본 위치는 `%LOCALAPPDATA%\SsakSsakKimchiDownloader\`이며, 기본 다운로드 위치는 사용자의 `다운로드\싹싹김치 다운로드\`입니다.

## 4. 브라우저 쿠키

브라우저 쿠키 사용은 기본적으로 꺼져 있습니다. 사용자가 설정에서 명시적으로 켠 뒤 로그인·연령 확인과 관련된 분석 오류가 발생한 경우에만 로컬 브라우저 쿠키 데이터베이스를 yt-dlp가 읽도록 요청합니다. 앱은 쿠키 값을 운영자 서버에 복사하거나 저장하지 않지만, 다운로드 대상 사이트에 인증 요청을 보내는 과정에서 해당 사이트가 쿠키를 수신합니다. 공용 PC에서는 이 기능을 켜지 마세요.

## 5. 외부 전송과 제3자

기능 수행을 위해 다음 서버에 직접 연결될 수 있으며, 해당 서비스는 IP 주소, 요청 헤더 및 사용자가 제공한 URL을 자체 정책에 따라 처리할 수 있습니다.

- 사용자가 입력한 영상/미디어 제공 사이트
- GitHub: 앱 릴리스와 운영자가 immutable URL·크기·SHA-256을 고정한 ffmpeg 파일
- 사용자가 직접 클릭한 외부 프로모션 또는 지원 링크

앱은 public HTTP(S) 목적지만 허용하도록 로컬·사설·link-local 주소와 사용자정보가 포함된 URL을 차단하지만, 대상 서비스의 개인정보 처리까지 통제하지는 않습니다.

## 6. 보유 기간과 삭제

운영자가 위 로컬 데이터를 별도로 보유하지 않습니다. 사용자는 앱 제거 후 `%LOCALAPPDATA%\SsakSsakKimchiDownloader\`와 다운로드 폴더의 파일을 직접 삭제할 수 있습니다. 진행 중 오류가 발생하면 데이터 손실 방지를 위해 복구용 작업 폴더가 보존될 수 있습니다.

## 7. 보안

업데이트 설치 파일은 허용된 HTTPS host, canonical 파일명, 크기, SHA-256, PE 형식, Authenticode signer 및 ProductVersion을 모두 확인합니다. 로그 URL은 redaction하며 설정 파일은 임시 파일·fsync·원자 교체 방식으로 저장합니다. 어떤 소프트웨어도 절대적인 보안을 보장할 수는 없습니다.

## 8. 아동, 국제 이전 및 권리 행사

대상 연령, 적용 법률, 국제 이전 고지, 개인정보 권리 행사 절차는 법적 운영 지역과 유통 국가를 확정한 뒤 추가해야 합니다. 문의는 확정된 개인정보 문의처로 접수합니다.

## 9. 변경

데이터 처리 방식이 달라지면 이 문서를 먼저 갱신하고 필요한 경우 앱 내 재동의를 받습니다. 중요한 변경의 시행일과 이전 버전 문서를 릴리스 기록에 보존합니다.
