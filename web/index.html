🥬 싹싹김치 다운로드
유튜브·인스타그램·비메오·틱톡 등 영상을 원하는 화질로 저장
⬇ Windows용 설치 프로그램
Windows 10/11 · 설치형 · 약 88MB(버전에 따라 달라질 수 있음)

주요 기능

다양한 사이트유튜브·인스타·비메오·틱톡·X 등
원하는 화질지원되는 경우 최고 8K, MP3 음원 추출
썸네일 미리보기받기 전에 영상 정보 확인
쿠키 기본 OFF명시적으로 허용한 로그인형 영상에만 사용

설치 방법

① 위 버튼으로 SsakSsakKimchiDownloader-Setup-v1.11.0.exe를 받습니다.
② 파일명과 아래 디지털 서명 안내를 확인한 뒤 설치 프로그램을 실행합니다.
③ 설치가 끝나면 시작 메뉴 또는 바탕화면의 싹싹김치 다운로더를 실행합니다.
④ 첫 실행 시 필요한 구성요소를 신뢰 검증 후 준비할 수 있어 인터넷 연결이 필요합니다.

실행 전 보안 확인

Windows 파일 속성의 디지털 서명이 유효하고, 표시된 게시자가 공식 v1.9 릴리스 안내의 게시자와 같은지 확인하세요. 서명이 없거나 유효하지 않음, 알 수 없는 게시자, 다른 파일명 또는 다른 게시자가 표시되면 실행하지 마세요. 경고를 우회하지 말고 GitHub Issues로 신고해 주세요.

본 프로그램은 사용자가 접근·저장 권한을 가진 콘텐츠를 위한 도구입니다. 저작권과 서비스 약관 준수 책임은 사용자에게 있습니다.
