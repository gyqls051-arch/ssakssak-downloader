#     유튜브 SABR 대응이 매 릴리스마다 들어가므로 항상 최신을 써야 한다.

# bgutil PO Token 공급자 (yt-dlp 플러그인 쪽 = 파이썬).

#   실제 스트림을 못 받는다(포맷 목록이 비거나 10MB 즈음 403). 이 패키지는
#   '토큰을 요청하는 쪽'이고, 실제로 토큰을 만드는 JS 서버는
#   prepare_potprovider.py 가 potprovider\ 에 따로 빌드한다.
#   ※ 둘의 버전이 맞아야 하므로 여기를 올리면 prepare_potprovider.py 의
#     BGUTIL_VERSION 도 같이 올릴 것.
bgutil-ytdlp-pot-provider>=1.3.1,<2
